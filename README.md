# CareerX Website & Policy Pages

This folder contains the complete, lightweight landing page and policy documents for **CareerX** (`com.careerx.app`), optimized for deployment on **GitHub Pages**.

## Files
- `index.html` - App landing page with features, stats, app screenshots, and support.
- `privacy-policy.html` - Google Play compliant privacy policy with data safety and account deletion terms.
- `terms-and-conditions.html` - Terms and conditions for CareerX users.
- `assets/` - CareerX logo and real app screen previews.
- `css/style.css` - Responsive mobile-first stylesheet.
- `js/main.js` - Lightweight client script.

## How to host on GitHub Pages:
1. Create a public repository on GitHub (e.g. `CareerXWebsite` or `<username>.github.io`).
2. Push all the contents of this folder to the repository's `main` branch.
3. In GitHub: Go to **Settings > Pages > Build and deployment**.
4. Set **Source** to `Deploy from a branch`, select `main` / `/(root)`, and click **Save**.
5. Your live links will be:
   - Landing page: `https://<username>.github.io/<repo>/`
   - Privacy Policy: `https://<username>.github.io/<repo>/privacy-policy.html`
   - Terms & Conditions: `https://<username>.github.io/<repo>/terms-and-conditions.html`
